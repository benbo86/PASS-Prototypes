Page capture

Pick an element on any web page, including logged-in pages such as the live PASS app, and save it as a file that can be handed to Claude to rebuild. It records the element tree, the styles that differ from browser defaults, sizes and positions, fonts and CSS variables.

1. Add the bookmarklet

Drag this to your bookmarks bar.

Capture page

If a site's security policy blocks bookmarklets, use “Copy script instead”, then paste it into the browser console (Cmd+Option+J) on that page and press Enter.

2. Capture

  1. Open the live page, signed in, and get it into the state you want (a menu open, a tab selected).
  2. Click the bookmarklet. Hover to highlight, then click the element to capture. Up/Down arrows select the parent or child.
  3. ⌘-click (Ctrl-click on Windows) passes a click through to the page, so you can open a menu while the picker is active.
  4. A capture-….json file downloads. Move it into the captures/ folder in this repo (ignored by git) and tell Claude its name.

Before you share a capture

A capture contains the text on the page, which on the live app can include customer and employee names. Tick Mask text in the picker bar to replace letters with “x” and digits with “0”, keeping the layout. Masked text is fine for layout and styling but hides real labels, so for a screen where the wording matters, capture unmasked and only share it if the content is safe to share. Password fields are never captured.

It doesn't capture canvas, video or iframe contents (they are marked as not captured), and it can't record behaviour such as what a click does. Add a screenshot or a note for those.
